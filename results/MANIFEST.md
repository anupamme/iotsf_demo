# What is in `results/`, and which of it the paper stands on

GENERATED by `scripts/emit_results_manifest.py` -- do not edit by hand.

Labels are derived by **observation**: each emitter `scripts/rederive_all.sh` runs is executed
with the flags that file gives it, under an audit hook recording every file it opens under
`results/` **and the call site that opened it** (`scripts/_trace_opens.py`).

Two observations decide CANONICAL, and it takes both. Almost every emitter imports
`cell_matrix`, whose `moirai_cells()` globs `results/**/*.json` and opens all of them in order
to *reject* the ones that are not paired B/D records -- so "an emitter opened it" is true of
nearly every directory here, including ones nothing uses. A directory is CANONICAL when either
a **targeted read** names it (a call site that was not that whole-tree scan) or a record inside
it **survived the scan's filter** (the loader is asked what it kept, not what it touched). The
second is what the main matrix arrives by; the first is what every other arm arrives by.

Two kinds of `run` line are deliberately NOT traced, and the count above reflects that.
`emit_results_manifest.py` is itself one of the sweep's `run` lines: tracing it would be
self-referential. And the 2 line(s) inside the sweep's optional-tier guards
(`gate ladder (recompute)`, `gate ladder val (recompute)`) refit the baseline ladder from the
benchmark CSVs, which are gitignored -- so tracing them would make this file impossible to
regenerate from a clean clone, which is the situation it exists to document. Nothing is lost:
those lines differ from their `--from-json` counterparts (traced) only in reading `data/*.csv`
and writing the ladder JSON that `--from-json` reads, so they reach no `results/` directory the
traced path does not. Every other `run` line is traced, figure scripts included.

- **CANONICAL** (56): a targeted read names it, or a record in it survived
  the matrix loader's filter. These are the directories the paper's numbers come from.
- **SUPERSEDED** (1): published, then corrected. Kept as the audit trail
  behind the corrections appendix. Do not read as current.
- **SCANNED** (78): opened only by the whole-tree scan, and nothing inside it
  survived that scan's filter. Being read and rejected is not being used. This is the honest
  limit of what tracing can show: it rules out the main matrix, and a targeted arm would have
  shown up as a call site, so nothing here is known to be load-bearing -- but the evidence is
  absence of a positive signal, not proof of irrelevance.
- **ORPHAN** (5): never opened at all, by any emitter, at any call site.

140 directories, 53 top-level JSON records, 30 registered emitters traced.
