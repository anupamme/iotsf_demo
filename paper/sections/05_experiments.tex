\subsection{Experimental Setup}
\label{sec:experiments:setup}
% ============================================================

\textbf{Dataset.}
We use \dataset{}~\cite{neto2023ciciot}, a publicly available benchmark
of labelled IoT network flows captured from 105 IoT devices spanning
33 attack categories.  Following standard practice, we extract 12
network-flow features (packet counts, byte volumes, inter-arrival times,
flow duration) and create 128-timestep sliding windows with stride 128.
We use a stratified 80/20 train/test split, maintaining class balance.

\textbf{Synthetic hard negatives.}
We generate 4 attack types (Eqs.~\ref{eq:slow}--\ref{eq:proto})
at 3 stealth levels (85\%, 90\%, 95\%), yielding 12 evaluation
conditions.  Protocol constraints (Modbus, MQTT, CoAP) are enforced
at the \emph{moderate} strictness tier by default.
Benign training samples are taken exclusively from the real \dataset{} benign split.

\textbf{Threshold calibration.}
To address the FPR=1.0 issue observed with default thresholds, we sweep
$(\delta_{\text{CI}}, \delta_{\text{rate}}) \in [0.5, 1.0) \times [0.05, 0.65)$
on a held-out validation set and select the operating point
maximising F1 score.  This is consistent across all Moirai variants.

\textbf{Baselines.}
We compare against nine methods:
(1)~Threshold IDS, (2)~Signature IDS, (3)~Statistical IDS,
(4)~Isolation Forest~\cite{liu2012isolation}, (5)~Ensemble~\cite{garcia2014empirical},
(6)~USAD~\cite{audibert2020usad}, (7)~TranAD~\cite{tuli2022tranad},
(8)~Anomaly Transformer~\cite{xu2022anomaly}, and
(9)~PatchTST-Anomaly~\cite{nie2023patchtst}.
All unsupervised methods are trained on benign sequences only,
using the same 80/20 split.

\textbf{Metrics.}
We report Accuracy, Precision, Recall, F1, False Positive Rate (FPR),
and ROC-AUC.  For IoT deployments, FPR and F1 are most operationally
relevant.  All results are averaged over 3 random seeds.

\textbf{Traditional IDS failure on hard negatives.}
All five traditional methods achieve high recall on real attacks
(average recall 88\% on \dataset{}) but collapse at stealth 95\%
(average recall $<$20\%).  This confirms that AI-generated hard
negatives are invisible to statistical and signature-based detectors.

\textbf{\ours{} outperforms all baselines.}
On stealth-95, \ours{} achieves F1 = 0.732 (ROC-AUC = 0.773), compared to
the best deep-learning baseline (Anomaly Transformer, F1 = 0.696) and
the best traditional baseline (Statistical IDS, F1 = 0.889 on standard traffic,
which degrades sharply against stealthy patterns).  The gap
is most pronounced for C2 Beaconing and Protocol Anomaly patterns,
which exploit periodic and timing-based evasion that detectors
trained only on benign distribution cannot anticipate.
On stealth-85, the advantage is even clearer: \ours{} achieves F1 = 0.818
(FPR = 0.300) versus zero-shot F1 = 0.691 (FPR = 0.767).

\subsection{Ablation Study}
\label{sec:experiments:ablation}
% ============================================================

\textbf{Hard negatives are essential.}
Comparing conditions C and D (both use NLL+SupCon), replacing real
attacks with synthetic hard negatives improves F1 by $+$0.073 points
on stealth-95 (0.659$\to$0.732) and ROC-AUC by $+$0.180 (0.593$\to$0.773).
Hard negatives create more informative negative
examples near the decision boundary.

\textbf{Contrastive loss helps.}
Comparing conditions B and D (both fine-tuned on hard negatives),
adding the contrastive loss improves F1 by $+$0.018 points on stealth-95.
The SupCon loss creates a more separable embedding space, visible in the
improved ROC-AUC ($+$0.015 at stealth-95).

\textbf{Protocol constraints matter.}
Comparing conditions D and E, disabling protocol constraints reduces
F1 by $-$0.012 points at stealth-95.  The effect is more pronounced
at the all-stealth level ($-$0.008 F1, $-$0.011 ROC-AUC),
confirming that protocol-valid synthetic attacks produce more
realistic training signal that transfers better to real-world detection.

\label{sec:experiments:constraints}
% ============================================================

that pass protocol validation at each strictness tier.

\input{tables/protocol_compliance}

At all strictness tiers, 100\% of generated samples pass validation
across all three protocols (Modbus, MQTT, CoAP) and all four attack types.
This confirms that the constraint retry loop (Algorithm~\ref{alg:hng})
reliably enforces protocol rules without compromising attack diversity.
The uniform compliance occurs because our diffusion-based synthesis
operates in a continuous latent space where protocol boundary violations
trigger targeted re-sampling rather than unconstrained generation.

\subsection{Hyperparameter Sensitivity}
\label{sec:experiments:hparams}
% ============================================================

Figure~\ref{fig:hparam} shows F1 on stealth-95 as a function of
contrastive weight $\lambda$ and temperature $\tau$.
Performance is stable across the range $\lambda \in [0.3, 0.7]$
and $\tau \in [0.05, 0.10]$, confirming that the default
$(\lambda=0.5, \tau=0.07)$ is near-optimal and the method is not
sensitive to precise hyperparameter tuning.
